# Jogo 3D de Terror — Unity Engine

Projeto final do curso de Qualificação Profissional em Desenvolvedor de Games com Unity 3D, oferecido pelo CETAM (Centro de Educação Tecnológica do Amazonas), com carga horária de 180h.

## Sobre o jogo

Você é um repórter em busca de um furo de reportagem: sete pessoas desapareceram nas proximidades de uma mansão abandonada, cercada por uma floresta escura. Ao investigar o local, você descobre que cada um dos desaparecidos deixou para trás um item — evidências que você precisa coletar antes de sair da floresta.

O problema é que você não está sozinho. Um monstro ronda a área e é capaz de detectar sua presença. Fugir dele enquanto procura os itens é o principal desafio do jogo.

### Controles

| Ação | Tecla |
|---|---|
| Mover | `W A S D` |
| Olhar ao redor | Mouse |
| Ligar/desligar lanterna | `F` |
| Equipar lanterna | `1` |
| Ver lista de itens | `2` |
| Slot extra (ex.: item especial) | `3` |

A lanterna consome bateria com o uso; pilhas para recarregá-la estão espalhadas pelo mapa. O slot extra pode receber itens especiais encontrados durante a exploração, como um machado capaz de abrir novas áreas do mapa.

## Tecnologias utilizadas

- **Unity Engine** (2019.3.15f1)
- **C#**
- **Shaders** (ShaderLab / HLSL)

## Observação sobre assets

Este repositório contém apenas o código e os assets autorais do projeto. Modelos, sons e outros recursos de terceiros obtidos gratuitamente na Unity Asset Store não estão incluídos, por questão de licença.

## Como abrir o projeto

1. Clone este repositório.
2. Abra o projeto pela Unity Hub, usando a versão **2019.3.15f1** (ou compatível).
3. Aguarde a Unity reimportar os assets.
